Site oficial do **Ponto do Assado** — o melhor frango assado na brasa e os bolos artesanais da Sara, em São Paulo. Este repositório contém o código-fonte completo do site, desenvolvido com as tecnologias mais modernas do ecossistema React.

## 🚀 Rodando o Projeto

### Pré-requisitos

- **Node.js** 18+
- **pnpm** instalado globalmente

```bash
npm install -g pnpm
```

### Instalação

```bash
# 1. Clonar o repositório
git clone https://github.com/RLluna12/assado.git
cd assado

# 2. Instalar dependências
pnpm install

# 3. Iniciar em modo desenvolvimento
pnpm dev
```

Acesse **[http://localhost:3000](http://localhost:3000)** no navegador.

### Scripts

```bash
pnpm dev      # Servidor de desenvolvimento com hot reload
pnpm build    # Build otimizado para produção
pnpm start    # Servidor de produção
pnpm lint     # Análise estática do código
```
